**文件**:

- `agent/lumio/shared/config.py`

**改动**:

2. `tracing.py:_TRACING_ENABLED` 改为从 `Settings` 读 (pydantic), 不再 `os.getenv` 裸读 — 与项目其它 12 个 `*Settings` 风格统一
3. `tracing.py:jaeger_host` 同上
4. `config.py` 新增 `ObservabilitySettings` 类 (env_prefix=`OBSERVABILITY_`), 含 `tracing_enabled: bool = True` / `jaeger_host: str = "localhost"` / `otlp_endpoint: str | None = None` (可选, 默认从 jaeger_host 拼)

**测试**: 不动 `test_observability.py` 现有 7 个 (它们 monkeypatch `_TRACING_ENABLED`, 兼容)

### Commit 2 — `feat(trace): MCP.call_tool span 增强 (server/duration/error)`

**文件**:
- `agent/lumio/services/common/mcp_client.py`

**改动**:
- `call_tool` 第 308 行 `@traced("MCP.call_tool", attrs_fn=...)` 拆为手动 span 控制, 加 server/duration/error 属性:
  ```python
  with tracer.start_as_current_span("MCP.call_tool") as span:
      span.set_attribute("mcp.tool", name)
      if target is not None:
          server, raw_name = target
          span.set_attribute("mcp.server", server)
      try:
          result = await session.call_tool(...)
          span.set_attribute("mcp.is_error", bool(result.isError))
          span.set_attribute("mcp.duration_ms", int((time.monotonic()-start)*1000))
          return ...
      except Exception:
          span.record_exception(err)
          span.set_status(Status(StatusCode.ERROR))
          raise
  ```
- 用 `mcp.is_error` 属性让"工具业务错误"在 trace 里可见
- 用 `mcp.duration_ms` 让 Jaeger 火焰图能排序

**测试**:
- `test_observability.py` 加 1 个 `test_mcp_call_tool_span_attributes`: InMemorySpanExporter + 触发 `call_tool` (mock session), 断言 span 含 `mcp.tool` / `mcp.is_error` / `mcp.duration_ms`

### Commit 3 — `feat(mcp-server): 切面用 Observation 包装, 工具调用变子 span`

**改动**:
1. `ToolCallAspect.java`:
   - 注入 `ObservationRegistry` (Spring Boot 已自动装配)
   - `Timer.start` + `meterRegistry.counter` 保留 (不破坏现有指标)
   - 包一层 `Observation.createNotStarted("mcp.tool.call", observationRegistry).observe(() -> ...)`:
     - `lowCardinalityKeyValue("tool", toolName)` / `("outcome", outcome)`
     - 异常路径: `observation.error(t)` (自动 record_exception + set_status=ERROR)

**收益**:
- Java 端 `mcp.tool.call` span 嵌套在 Python 端 `MCP.call_tool` span 之下, 跨服务 trace 真正形成父子链
